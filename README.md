# it7ad molak | إتحاد ملاك
Building expenses and resident-fee app (it7admolak.com). Keep this repository PRIVATE. Never save passwords or secret keys here.

- app.html = the app (published as /app/). index.html = landing page. The other icon/manifest files are part of the site.
- sql-XX-... = database scripts for Supabase. Run in number order, once each. sql-backup-... is run before every update.
- build.sh puts the website files in the "site" folder that Cloudflare publishes.
